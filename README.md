Official SeekMall installer downloads and release notes.

Visit [Releases](https://github.com/SamSeekmall/seekmall-releases/releases) and choose an installer from the **Assets** section of a published release.

## About this repository
This public repository is for installer distribution and release documentation only. The SeekMall application source code is private and is not included in this repository.
