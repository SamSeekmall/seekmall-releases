# SeekMall Releases
Official SeekMall installer downloads and release notes.
## Download
Real downloads are stored in this repository. They are ZIP files, not GitHub Release assets.

- [Media Companion 0.3.8 Windows x64 portable preview](packages/media-companion/0.3.8-preview/DELIVERY.json): bundled Node, FFmpeg/ffprobe, runtime dependencies and the complete matching source ZIP. Native Windows/GPU acceptance is pending.
- [Media Toolkit 0.2.9 desktop Chrome unpacked ZIP](packages/media-toolkit/0.2.9-agpl3/): actual extension files, own component source and AGPL-3.0-only license.

Download file links and SHA256 are recorded in each delivery manifest. Preserve source and license files when redistributing. Earlier MIT component distributions remain available with their original grants.
## About this repository
This public repository distributes installers, matching component/dependency sources and release documents. It does not make all SeekMall repositories public or replace their licenses. The Companion own code is AGPL-3.0-only; bundled FFmpeg is GPL-3.0-or-later and other dependencies retain their own terms. Player website publication/source-download gates remain separate.
